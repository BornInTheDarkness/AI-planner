## Локальный baseline

На ветке этапа 0 подготовлены интерактивный web-прототип, FastAPI-каркас,
пространственный JSON Schema, локальная инфраструктура и CI.

```bash
cp .env.example .env
make bootstrap
make infra
make api  # отдельный терминал
make web  # отдельный терминал
```

Правила разработки и проверки описаны в [`CONTRIBUTING.md`](CONTRIBUTING.md).

## Статус

Проект находится на этапе 0: discovery и технический фундамент. Текущая цель —
проверить основную персону и P0-путь, затем согласовать архитектурные границы перед
реализацией vertical slice.
