# P0-сценарии этапа MVP

## P0-01. Создать и повторно открыть проект

**Результат пользователя:** проект с локалью, единицами и регионом сохранён и
доступен только владельцу.

**Основной поток:** регистрация или гостевой режим → создание проекта → ввод
минимальных параметров → сохранение → повторное открытие.

**Приёмка:** нет доступа к чужому проекту; последняя подтверждённая версия
восстановлена; гостю ясно сообщён срок жизни данных и ограничения экспорта.

## P0-02. Получить корректную исходную геометрию

**Результат пользователя:** план загружен либо создан вручную и откалиброван.

**Основной поток:** выбор источника → проверка формата → загрузка → распознавание →
просмотр confidence → указание известного размера → исправление стен и проёмов.

**Ветви:** неподдерживаемый файл; malware/quarantine; нет известного размера;
низкая уверенность; ручное создание простой прямоугольной комнаты.

**Приёмка:** исходник не изменён; ошибки распознавания не скрыты; пользователь
может завершить сценарий вручную; каноническая модель валидна по JSON Schema.

## P0-03. Сформировать и сравнить варианты

**Результат пользователя:** минимум два отличающихся валидных варианта либо
понятное объяснение несовместимых требований.

**Основной поток:** заполнение брифа → проверка ограничений → запуск job → прогресс →
валидация кандидатов → сравнение площади проходов, бюджета и соответствия брифу.

**Приёмка:** повтор с тем же idempotency key не создаёт второй job; отмена не
публикует частичный результат; невалидный вариант не помечается готовым;
компромиссы и источник AI-результата видимы.

## P0-04. Отредактировать и сохранить выбранный вариант

**Результат пользователя:** выбранный вариант можно изменить без потери исходной
версии.

**Основной поток:** выбор варианта → перемещение/замена объекта → проверка
коллизий → undo/redo → сохранение новой версии → повторное открытие.

**Приёмка:** конфликт версий не перезаписывает чужое изменение; размеры можно
ввести точно; интерфейс объясняет предупреждения; типовые операции работают без
заметной задержки.

## P0-05. Получить визуализацию, смету и экспорт

**Результат пользователя:** воспроизводимый пакет выбранной версии.

**Основной поток:** выбор стиля → preview → просмотр спецификации и цен → экспорт
PNG/PDF/JSON.

**Приёмка:** артефакты связаны с одной версией; AI-изображение обозначено; дата и
источник цены видимы; отчёт содержит предупреждения; ссылка на скачивание
короткоживущая; повторная генерация не удаляет сохранённый результат.

## Сквозные требования

- ключевые операции доступны с клавиатуры и имеют понятные focus states;
- пользователь знает состояние сохранения и фонового задания;
- аналитика не содержит план, изображение или prompt;
- критичные изменения конструкции и зон требуют явного предупреждения;
- удаление проекта немедленно закрывает доступ и запускает физическую очистку по
  утверждённой retention policy.
