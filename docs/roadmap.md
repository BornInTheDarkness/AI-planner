# План реализации

Сроки уточняются после выбора команды и согласования требований. Оценки ниже —
относительные, а не обещание календарной даты.

## Этап 0. Discovery и фундамент (2–3 недели)

**Результаты:** утверждённые персоны и P0-сценарии; 10–15 интервью; прототип
редактора; выбор региона/провайдеров; threat model; ADR; репозиторий, CI и среды.

**Критерий выхода:** проверен главный пользовательский путь, определены метрики,
стоимостные лимиты AI и владельцы данных.

## Этап 1. Vertical slice (4–6 недель)

**Результаты:** аккаунт, проект, ручная простая комната, сохранение версий,
базовый 2D canvas, один background job, telemetry и deployment в staging.

**Критерий выхода:** пользователь создаёт и повторно открывает проект; e2e проходит
в CI; backup восстановлен в тестовой среде.

## Этап 2. Импорт и AI-планировка (5–8 недель)

**Результаты:** upload pipeline, распознавание плана, коррекция масштаба, бриф,
генерация 2–3 вариантов, детерминированные валидаторы, quality dataset.

**Критерий выхода:** согласованные пороги на тестовом наборе; сбой провайдера не
теряет проект; пользователь понимает и исправляет низкую уверенность.

## Этап 3. Визуализация, каталог и экспорт (4–6 недель)

**Результаты:** style presets, preview render, минимальный каталог, смета,
PDF/изображение/JSON экспорт, квоты и управление стоимостью.

**Критерий выхода:** полный P0-путь работает в staging, provenance и цена
генерации наблюдаемы, экспорт воспроизводится из версии проекта.

## Этап 4. Закрытая beta (3–4 недели)

**Результаты:** пилот ≥30 проектов, accessibility/security review, support runbooks,
privacy/legal документы, dashboards и on-call, исправление критических дефектов.

**Критерий выхода:** выполнены критерии MVP из ТЗ и принято решение о запуске.

## Приоритетный backlog

| Приоритет | Возможность |
|---|---|
| P0 | Проекты, импорт/ручной ввод, 2D-коррекция, бриф, варианты, preview, экспорт |
| P0 | Authz, удаление данных, audit, observability, budget limits, recovery |
| P1 | Комментарии, share link, расширенный каталог, сравнение смет |
| P1 | Простой 3D walkthrough, локализация, подписка |
| P2 | Realtime collaboration, AR/LiDAR, marketplace, мобильные приложения |

## Риски и меры

| Риск | Мера |
|---|---|
| Неточная геометрия из изображений | human-in-the-loop, confidence, golden dataset |
| Правовая опасность советов | предупреждения, rule packs по регионам, экспертная проверка |
| Высокая стоимость AI/рендера | quotas, кэш, tiered quality, cost telemetry, cancellation |
| Vendor lock-in | provider adapters, канонические схемы, хранение собственных артефактов |
| Низкое доверие к результату | объяснения, provenance, редактирование и сравнение вариантов |
| Утечка планов жилья | минимизация, строгий authz, encryption, retention, audit |
| Слишком широкий MVP | жёсткие P0 gates и отдельный post-MVP backlog |
