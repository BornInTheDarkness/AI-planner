# ADR-005: AI Gateway, адаптеры и provenance

- **Статус:** Proposed
- **Дата предложения:** 2026-09-17
- **Владелец:** требуется назначить

## Контекст

AI-провайдеры различаются контрактами, регионами, политиками данных, качеством и
стоимостью. Домен не должен зависеть от конкретного SDK.

## Решение

Внутренний AI Gateway принимает версионированный запрос, выбирает provider adapter,
применяет deadline/квоту и возвращает строгую схему. Он записывает provider, model,
prompt revision, параметры, latency, usage и cost. Контент пользователя не пишется
в telemetry. После Gateway всегда выполняются детерминированные валидаторы.

## Последствия

Интеграция требует собственных contract tests и offline evaluation. Абстракция не
обещает идентичный результат разных моделей; показатели качества ведутся отдельно.

## Пересмотр

Если один on-premise provider станет утверждённой платформой и стоимость
поддержания нескольких адаптеров превысит пользу.
