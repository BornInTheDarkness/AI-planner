# ADR-006: Next.js/TypeScript и FastAPI/Python

- **Статус:** Proposed
- **Дата предложения:** 2026-09-17
- **Владелец:** требуется назначить

## Контекст

Продукту нужен сложный web-редактор, versioned API и тесная интеграция с AI/CV и
геометрическими библиотеками. Командные компетенции ещё не подтверждены.

## Решение

Использовать Next.js/React со строгим TypeScript для web и FastAPI/Pydantic на
Python 3.12 для API/workers. Контракт между ними описывается OpenAPI/JSON Schema;
клиентские типы в дальнейшем генерируются, а не дублируются вручную.

## Последствия

Два runtime увеличивают объём tooling, но позволяют использовать подходящие
экосистемы для UI и AI/CV. Монорепозиторий, единый CI и Docker Compose уменьшают
стоимость локальной интеграции. Текущий прототип проверяет baseline, но не является
подтверждением выбора командой.

## Альтернативы

Полный TypeScript упрощает runtime, но снижает удобство части AI/CV-экосистемы.
Полный Python не подходит для требуемого интерактивного web-клиента.

## Пересмотр

До vertical slice — после аудита навыков команды и spike редактора. После начала
production-разработки — только при измеримой проблеме.
