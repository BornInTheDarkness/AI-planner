# Пакет интервью I-01 — I-12

В папке находятся 12 отдельных обезличенных записей в структуре из
[`interview-plan.md`](../../discovery/interview-plan.md).

## Статус

17.09.2026 владелец продукта поручил использовать пакет как рабочий эквивалент
интервью для решений этапа 0. Записи включены в
[`evidence-map.md`](../evidence-map.md) и
[`synthesis-2026-09-17.md`](../synthesis-2026-09-17.md).

Каждый исходный файл содержит явную пометку о моделируемой записи и синтетических
формулировках. Поэтому пакет имеет статус `proxy`: он учитывается во внутреннем
синтезе, но не используется как доказательство факта проведения внешних интервью
или как источник дословных цитат. Исходные записи не редактируются, чтобы
сохранить происхождение материала.
